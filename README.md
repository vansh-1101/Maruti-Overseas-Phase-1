# Maruti Overseas Consultancy Website

A modern website for Maruti Overseas Consultancy - helping students study abroad.

## 🚀 How to Run

1. **Open the project folder**
   ```
   cd maruti-overseas-enterprise
   ```

2. **Install packages**
   ```
   npm install
   ```

3. **Start the website**
   ```
   npm run dev
   ```

4. **Open in browser**
   - Go to: http://localhost:3000

## 📁 Project Structure

- **maruti-overseas-enterprise/** - Main website (work here!)
- **images/** - Pictures and images
- **TechSpec.md** - Technical details

## ✨ What's Inside

- Homepage with animations
- 7 country pages (USA, UK, Canada, Australia, Germany, New Zealand, Ireland)
- WhatsApp button for instant contact
- Search tool (press Cmd+K or Ctrl+K)
- Mobile-friendly menu
- Student tools (Course Finder, Cost Calculator, etc.)

## 🛠️ Built With

- Next.js (React framework)
- TypeScript
- Tailwind CSS (for styling)
- Framer Motion (for animations)
