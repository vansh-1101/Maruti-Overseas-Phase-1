# Maruti Overseas Consultancy - New Website

## Overview
This is the redesigned website for Maruti Overseas Consultancy, built with modern HTML5, CSS3, and vanilla JavaScript for optimal performance and user experience.

## Features
- ✅ Modern, premium design with smooth animations
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Fast loading with optimized assets
- ✅ SEO-friendly structure
- ✅ Interactive elements and smooth scrolling
- ✅ Professional color scheme and typography
- ✅ Comprehensive service showcase
- ✅ Country-specific visa information
- ✅ Contact form with validation
- ✅ Trust signals and testimonials

## Pages Included
1. **index.html** - Homepage with hero, services, countries, testimonials

## How to Run
1. Open `index.html` in any modern web browser
2. No server required for static pages
3. For contact form to work, you'll need to integrate with a backend service or email API

## Design System
The website uses a comprehensive design system with:
- **Color Palette**: Deep Blue (#0A3B5C), Gold (#D18837), Light Blue (#E3F0FA)
- **Typography**: Poppins for headings, Inter for body text
- **Spacing**: Consistent spacing scale (4px to 96px)
- **Components**: Reusable buttons, cards, grids
- **Animations**: Smooth fade-in, slide, and hover effects
